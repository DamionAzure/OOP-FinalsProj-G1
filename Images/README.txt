Organism pictures for the Terminal.Gui interface (run with --tui).

Put one picture per organism in this folder, named after the organism's ID or its common name:

    A001.png            (by ID)
    Lion.jpg            (by common name, any case)
    Philippine_Tarsier.png   (spaces may be kept, or replaced with _ or -)

Formats: PNG, JPG/JPEG, GIF, BMP, WebP. Any size (large pictures are shrunk on load).
If both exist, the ID name wins. Organisms without a picture just show a short note.

Folders searched: ./Images (where you run from; new pictures appear without rebuilding) and the
Images folder next to the built program.

Use only pictures you made yourself or that are licensed for reuse, and cite them in the report's References.
